أنت خبير React.js وكاتب محتوى تعليمي بالعامية المصرية، ومهمتك إنك تكتب ملف Markdown واحد كبير (بأسلوب Obsidian) اسمه "React من الصفر — إنترفيو الريأكت" يغطي أشهر أسئلة الإنترفيوهات عن React بالترتيب ده بالظبط، من صفر مطلق لأعمق نقطة في كل موضوع، عشان أذاكر منه لإنترفيو.

**ملحوظة إلزامية عن شكل الـ Output:** المطلوب منك تنتج **ملف Markdown حقيقي (.md) كـ Artifact/File فعلي** مش رد نصي عادي جوا الشات. يعني:
- استخدم كل تنسيقات الـ Markdown الصحيحة (العناوين بـ `#`، `##`، `###`، الـ Code Blocks بـ ``` ثلاث backticks، الـ Callouts بصيغة `> [!info]`/`> [!tip]`/`> [!warning]`/`> [!danger]`، الجداول بصيغة Markdown Tables، الـ Frontmatter بين `---`).
- الملف كله لازم يتكتب كـ **مستند واحد متصل من Q1 لآخر سؤال**، مش مقسّم لردود منفصلة أو ملخصات جانبية.
- ابدأ الرد بالـ Frontmatter مباشرة من غير أي مقدمة أو كلام قبله، وخلّي كل حاجة بعد كده جزء من نفس الملف.

**ملحوظة مهمة عن طول الإجابة (الفرق الأساسي عن ملفاتي التانية):** الملف ده المطلوب فيه إجابات **مختصرة نسبياً** مش دسمة زي باقي الملفات. يعني:
- "أصل الحكاية" هنا فقرة **قصيرة** (3-4 جمل بحد أقصى) توصل الفكرة والمشكلة اللي بتتحل، من غير حواديت طويلة أو ربط مفصّل بكل سؤال سابق.
- مثال كود **واحد بس** واضح ومباشر لكل سؤال (مش 2-3 أمثلة إضافية زي الملفات التانية).
- "الفايدة الانترفيوية" هنا سؤال إنجليزي + **إجابة مثالية قصيرة** (2-3 جمل بس، مش فقرة كاملة) تلخص جوهر الإجابة اللي تتقال في الإنترفيو مباشرة.
- الهدف إن الملف يبقى **مرجع سريع للمراجعة** قبل الإنترفيو بيوم أو اتنين، مش دورة تدريبية كاملة.

## بنية كل سؤال (طبّقها بالظبط على كل Q):

1. **عنوان السؤال** بصيغة سؤال عامي طبيعي: `## Q{N} — [السؤال هنا بالعامية؟]`

2. **`### أصل الحكاية`** — فقرة عامية **قصيرة ومباشرة** (3-4 جمل) بتشرح المفهوم والمشكلة اللي بيحلها من غير إطالة.

3. **كود React واحد** (Functional Components + Hooks كافتراضي، إلا لو السؤال عن Class Components تحديداً) فيه **كومنتات إنجليزي بس جوا الكود** — مثال واحد واضح ومباشر يوضح المفهوم، مع جملة قصيرة قبله أو بعده تشرح النقطة المهمة فيه.

4. **مثال واحد إضافي بس (اختياري حسب الحاجة)** لو فيه edge case مهم أو فخ شائع لازم يتوضح — مش أكتر من كده.

5. **`### الفايدة الانترفيوية`** — تتكون من جزئين:
   - **صيغة السؤال بالإنجليزي** بالظبط زي ما هيتسأل في الإنترفيو.
   - **`**الإجابة المثالية:**`** — **2-3 جمل بس** (مش فقرة كاملة) تلخص جوهر الإجابة، جاهزة تتقال في الإنترفيو مباشرة بدون حشو.

6. **Callouts حسب الحاجة (باختصار):**
   - `> [!tip] Checkpoint` — جملة واحدة ملخصة
   - `> [!warning]` — فخ شائع في جملة أو اتنين
   - `> [!danger]` — فخ خطير بيبان في الإنترفيو بالظبط

7. **`---`** فاصل بين كل سؤال والتاني.

## قواعد اللغة والأسلوب:

- **الشرح النثري كله بالعامية المصرية** — مفيش فصحى خالص (إلا "الإجابة المثالية" ممكن عربي فصيح بسيط)
- **الكومنتات جوا الكود إنجليزي بس**
- **الإنجليزي في الشرح النثري ممنوع** — حتى لو الكلمة تقنية، اكتبها بالعربي وحط الإنجليزي بين قوسين، مثلاً: "الـ virtual dom"
- **الاختصار هو القاعدة الأساسية هنا**: لو حسيت إنك بتكتب فقرة طويلة، وقف واختصرها. الهدف كثافة معلومة عالية في مساحة صغيرة، مش شرح شامل زي باقي الملفات.
- ماتكتبش خاتمة أو ملخص في آخر الملف — كمل شرح لآخر لحظة
- استخدم جداول (Markdown Tables) لتوضيح المقارنات السريعة (زي `useMemo` مقابل `useCallback`، أو Controlled مقابل Uncontrolled Components) بدل الشرح النثري الطويل، لأن الجدول أسرع للمراجعة

## المحتوى المطلوب بالترتيب ده بالظبط:

### 📌 الموضوع 1: React Fundamentals
غطّي الأسئلة دي بالتسلسل:
- إيه الـ React أصلاً وإيه المشكلة اللي بيحلها؟
- إيه الـ Virtual DOM وإزاي بيختلف عن الـ Real DOM؟
- إزاي الـ Reconciliation Algorithm (الـ Diffing) بيشتغل عشان يحدّث الـ DOM بأقل تكلفة؟
- إيه الـ JSX وإزاي بيتحول لـ JavaScript فعلي وقت الـ Build؟ (`React.createElement`)
- إيه الفرق بين الـ Elements والـ Components في React؟
- إيه الفرق بين الـ Functional Components والـ Class Components؟
- إيه الـ `key` prop في الـ Lists وليه مهم جداً وإيه اللي بيحصل لو استخدمت الـ index كـ key؟
- إيه الفرق بين الـ Library والـ Framework؟ وليه React بتتصنف Library مش Framework؟

### 📌 الموضوع 2: Components & Props
غطّي الأسئلة دي بالتسلسل:
- إيه الـ Props وإزاي بتنتقل البيانات من Component لـ Component تاني؟
- إيه معنى إن الـ Props تكون Read-Only (Immutable)؟
- إيه الـ `children` prop وإزاي بتستخدمه لعمل Components قابلة لإعادة الاستخدام؟
- إيه الفرق بين الـ Props والـ State؟
- إيه الـ Prop Drilling وإيه المشكلة اللي بيسببها في الـ Component Tree الكبيرة؟
- إيه الـ Composition وإزاي React بينصح بيها بدل الـ Inheritance بين الـ Components؟
- إيه الـ Controlled Components والـ Uncontrolled Components في الـ Forms؟ (جدول مقارنة)
- إيه الـ Higher-Order Components (HOC) وإيه المشكلة اللي بتحلها؟
- إيه الـ Render Props Pattern وإزاي بيختلف عن الـ HOC؟

### 📌 الموضوع 3: State & Hooks
غطّي الأسئلة دي بالتسلسل:
- إيه الـ State وإزاي بيختلف عن الـ Props في التحكم فيه؟
- إيه الـ `useState` Hook وإزاي بيشتغل؟
- ليه بنستخدم الـ Functional Update Form في `setState` (`setCount(prev => prev + 1)`) بدل القيمة المباشرة أحياناً؟
- إيه قواعد استخدام الـ Hooks الأساسية؟ (متستخدمهاش جوا Loops أو Conditions أو Nested Functions)
- إيه الـ `useContext` Hook وإزاي بيحل مشكلة الـ Prop Drilling؟
- إيه الـ `useReducer` Hook وإمتى تستخدمه بدل `useState`؟
- إيه الفرق بين `useReducer` وRedux؟ (سؤال بيتلخبط فيه ناس كتير)
- إيه الـ Custom Hooks وإزاي بتعمل واحد لإعادة استخدام منطق معين بين Components؟
- إيه الـ `useRef` Hook وإزاي بيختلف عن الـ State في إنه مبيعملش Re-render؟
- إمتى تستخدم `useRef` عملياً؟ (الوصول لـ DOM Element، أو تخزين قيمة بين الـ Renders من غير Re-render)

### 📌 الموضوع 4: Lifecycle & Effects
غطّي الأسئلة دي بالتسلسل:
- إيه الـ Component Lifecycle الأساسي؟ (Mounting، Updating، Unmounting)
- إيه الـ `useEffect` Hook وإزاي بيحاكي الـ Lifecycle Methods بتاعت الـ Class Components؟
- إيه الـ Dependency Array في `useEffect` وإزاي بيتحكم في إمتى الـ Effect بيتنفذ تاني؟
- إيه الفرق بين `useEffect` بـ Dependency Array فاضية `[]` وبدون Dependency Array خالص؟
- إيه الـ Cleanup Function في `useEffect` وإمتى بتتنفذ؟ (زي إلغاء Subscription أو Timer)
- إيه أشهر فخ في `useEffect`؟ (الـ Infinite Loop لما تنسى الـ Dependency Array أو تحط فيها Object/Array بيتغيّر كل Render)
- إيه الفرق بين `useEffect` و`useLayoutEffect`؟

### 📌 الموضوع 5: Performance Optimization
غطّي الأسئلة دي بالتسلسل:
- ليه Component بيعمل Re-render أصلاً؟ (تغيير الـ State، الـ Props، أو الـ Parent بتاعه)
- إيه الـ `React.memo` وإزاي بيمنع Re-render غير ضروري للـ Component؟
- إيه الـ `useMemo` Hook وإمتى تستخدمه؟
- إيه الـ `useCallback` Hook وإزاي بيختلف عن `useMemo`؟ (جدول مقارنة: بيرجع قيمة مقابل بيرجع function)
- إيه فخ استخدام `useMemo`/`useCallback` في كل حتة بدون داعي؟ (تكلفة الـ Memoization نفسها ممكن تبقى أكتر من فايدتها)
- إيه الـ Code Splitting وإزاي `React.lazy` و`Suspense` بيقللوا حجم الـ Bundle الأولي؟
- إيه الـ Virtualization (زي `react-window`) وإمتى تحتاجها مع الـ Lists الطويلة جداً؟

### 📌 الموضوع 6: Routing & State Management
غطّي الأسئلة دي بالتسلسل:
- إيه الـ React Router وإيه المشكلة اللي بيحلها في الـ Single Page Applications؟
- إيه الفرق بين الـ Client-Side Routing والـ Server-Side Routing؟
- إيه مشكلة الـ "Prop Drilling على مستوى التطبيق كله" اللي بتخلينا نحتاج State Management Library؟
- إيه الـ Context API وإمتى بتبقى كفاية بدل مكتبة خارجية زي Redux؟
- إيه الـ Redux بشكل عام؟ (Store، Actions، Reducers) وإيه فايدته في تطبيقات كبيرة؟
- إيه الفرق بين الـ Context API والـ Redux من ناحية الأداء مع تحديثات متكررة؟
- إيه الـ React Query (أو SWR) وإيه المشكلة اللي بتحلها في التعامل مع الـ Server State تحديداً؟ (Caching، Refetching، Loading/Error States جاهزة)

### 📌 الموضوع 7: Advanced Patterns & أسئلة متفرقة شائعة
غطّي الأسئلة دي بالتسلسل:
- إيه الـ Error Boundaries وإزاي بتمسك الأخطاء في شجرة الـ Components من غير ما التطبيق كله يقفل؟
- إيه الـ Portals في React وإمتى تستخدمها؟ (زي عمل Modal لازم يطلع بره الـ DOM hierarchy بتاعت الـ Component)
- إيه الـ Fragments (`<>...</>`) وليه بنستخدمها بدل ما نلف الـ JSX بـ `div` زيادة؟
- إيه الفرق بين الـ SSR (Server-Side Rendering) والـ CSR (Client-Side Rendering) والـ SSG (Static Site Generation)؟
- إيه الـ Hydration في سياق الـ SSR؟
- إيه الـ Strict Mode في React وليه بيعمل بعض الأكواد تتنفذ مرتين في الـ Development؟
- إيه الفرق بين الـ Synthetic Events في React والـ Native DOM Events؟
- إيه أشهر سؤال إنترفيو: "إيه اللي بيحصل بالظبط لما تعمل `setState`؟" وإزاي تجاوب عليه بإيجاز يوضح إنك فاهم الـ Batching والـ Re-render؟
